CREATE & CUSTOMIZE

Your tools.
Your way.

Change an installed source extension, or create a new one in its own folder. Give our AI extension guide to your coding assistant to help write JavaScript or native Swift code, prompts, and settings.

  1. Make a tool your own. In MacHelper → Extensions, choose an installed source tool → Edit Source. Save your changes; an enabled tool reloads automatically. Native Swift edits compile and replace only that tool’s worker.
  2. Build something new. Ask your AI assistant to read the guide and create a source package. Use Install Source… in MacHelper, review its access, then enable it.
Read the AI guide (English) ↗Download for your AI ↓

The technical AI guide is in English. Code, prompts, and package names are preserved.

One MacHelper interface supports JavaScript and native Swift tools. The manifest selects execution and reload automatically. Native source needs compiler tools and native execution approval. Chrome/Edge companions use the browser’s reload control.
